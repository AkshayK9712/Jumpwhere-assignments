# Demo materials

| File | What |
|---|---|
| `DEMO_SCRIPT.md` | A 6 to 8 minute script (what to click and what to say) for recording the demo video |
| `screenshots/README.md` | The list of screenshots to capture, with file names |

Record the video with your screen recorder (OBS Studio, Xbox Game Bar with Win+G, or QuickTime) and save it here as `demo.mp4` (or share a link in this file). Put the screenshots in `screenshots/`.
